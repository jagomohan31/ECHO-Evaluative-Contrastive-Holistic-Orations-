# SpeechLens: Contrastive Speech Analytics

An interactive web dashboard for objective, contrastive speech evaluation and flaw localization.
Evaluates delivery (pacing, intonation, fluency, volume, clarity) relative to historical baseline orators.

## Demo

Load any of the 10 pre-analyzed demo clips from the selector. No upload required.
